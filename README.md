# Anarchia Cheats — Fabric 1.21.11

Client-side Minecraft Java mod project targeting **Minecraft 1.21.11**, Fabric Loader and Fabric API.

## Features in this prototype
- Open the purple ClickGUI with **Right Shift**.
- Categories: Combat, Movement, Player, Render, Misc and Settings.
- UI toggle buttons are currently visual/demo toggles only; they do not implement cheat functionality.

## Build
1. Install **Java 21** and a recent Gradle installation (Gradle 9.7.1 recommended).
2. Open this folder in IntelliJ IDEA or run `gradle build`.
3. The output JAR will be in `build/libs/`.

Dependencies are pinned in `build.gradle`: Minecraft 1.21.11, Yarn 1.21.11+build.3, Fabric Loader 0.19.5, Fabric API 0.141.6+1.21.11, Fabric Loom 1.18.2.
